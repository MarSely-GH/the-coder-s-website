# ИоПиВОР

Веб-приложение помощника инспектора по пропускному и внутриобъектовому режимам.

Приложение работает как PWA: его можно открыть по HTTPS в Яндекс Браузере и установить как приложение/ярлык на рабочий стол.

## Публикация

Публикация настроена через GitHub Pages workflow в `.github/workflows/pages.yml`.
